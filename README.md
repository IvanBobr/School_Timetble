## 📖 Описание
Система автоматически подтягивает данные об изменениях и подставляет их в общее расписани. Имеется несколько режимов работы:
  - с сервером для администрации (находится на главном компьютере, куда скачиваются новые данные о расписании и изменениях)
  - общее приложение для всех

В самом приложении расписание можно просматривать для конкретного класса на текущий день (только будущие уроки, либо все), на все дни - общее расписание, а также на текущий урок для всех классов.

## 🚀 Установка и запуск

### Для пользователей (без Python)
1. Скачайте последний релиз с [GitHub Releases](https://github.com/ваш_логин/репозиторий/releases).
2. Для клиента: запустите `TimetableClient`.  
   Для сервера: положите файлы `rasp.xls` и `changes.docx` в папку `downloads/` рядом с `TimetableServer` и запустите его.

### Для разработчиков (из исходников)
```bash
git clone https://github.com/ваш_логин/репозиторий.git
cd репозиторий
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python code/server.py      # запуск сервера
python code/timetable.py   # запуск клиента
